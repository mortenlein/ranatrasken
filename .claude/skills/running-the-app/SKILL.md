# Running Ranatrasken

## Prerequisites (one-time)

- `.env` must exist (copy `.env.example`): `DATABASE_URL="file:./dev.db"`, a generated
  `AUTH_SECRET`, and `NEXT_PUBLIC_MAPTILER_KEY`. **The MapTiler key may be empty** — the
  basemap/terrain then 403 (console noise, brown background) but the DNT trail overlay,
  route lines, markers, and all UI still work, which is enough for most verification.
- `npx prisma migrate deploy` once to create `dev.db`.

## Start / stop the dev server

```bash
npm run dev   # Next.js + Turbopack on http://localhost:3000, ready in ~1s
```

Run it in the background and poll `curl -sf http://localhost:3000` until it serves.
Stop it by killing the port listener (plain `kill` misses the detached child on Windows):

```powershell
Get-NetTCPConnection -LocalPort 3000 -State Listen |
  Select-Object -ExpandProperty OwningProcess -Unique |
  ForEach-Object { Stop-Process -Id $_ -Force -Confirm:$false }
```

## Drive it headlessly

`chromium-cli` is **not** installed here. Use playwright-core with the system Chrome:

```bash
npm i --no-save playwright-core   # node_modules is gitignored; package.json stays clean
```

```js
import { chromium } from 'playwright-core';
const browser = await chromium.launch({ channel: 'chrome', headless: true }); // or 'msedge'
const page = await browser.newPage({ viewport: { width: 1600, height: 900 } });
await page.goto('http://localhost:3000', { waitUntil: 'domcontentloaded' });
await page.waitForSelector('canvas', { timeout: 60000 });
await page.waitForTimeout(6000); // initial tile/terrain settle — no DOM signal exists
```

Representative interaction: `await page.click('text=Selforsfjellet')` (sidebar list) →
map flies to the destination over ~3s, tiles load — wait ~9s total — then screenshot and
confirm the blue curated footpath and red DNT trails are visible.

### Map introspection

The MapLibre instance is module-scoped, not on `window`. For scripted assertions
(`queryRenderedFeatures`, `getTerrain`, `project`), temporarily add inside the map-init
effect of `src/components/MapComponent.tsx` (after `map.current = mapInstance;`):

```ts
if (process.env.NODE_ENV === 'development') {
  (window as unknown as { __map?: maplibregl.Map }).__map = mapInstance;
}
```

Remove it before committing. Ready-made drivers from a previous session may exist in
`temp/drive.mjs` and `temp/verify.mjs` (gitignored; verify.mjs is an 8-check e2e suite).

### Signing in / admin

NextAuth credentials accept **any email** (auto-creates the user). Click the
`Logg inn` button → default NextAuth form → `fill input[name="email"]` → submit.
An email containing `admin` (e.g. `admin@e2e.local`) unlocks the Admin Curation panel;
"Enable" it, select a destination, then click a red DNT trail on the map (project a
trail vertex to screen coords via the `__map` hook) to select segments.

## Gotchas

- Without a MapTiler key every `api.maptiler.com` request 403s — filter that noise out
  of console/network logs before judging errors.
- `wait-idle`-style strategies never settle (map keeps rendering); use fixed waits.
- Route data: `src/data/routes.json` is generated by `node scripts/build-routes.mjs`
  (cached inputs under `temp/`); the dev server hot-reloads when it changes.
